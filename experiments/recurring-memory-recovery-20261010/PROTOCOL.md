# Recurring-context memory: frozen experiment

Claim: does retrieving past released feedback by an observable cue speed
adaptation when a situation returns, without more confident mistakes in novel
or changed situations? Keep all failures. No held-out retuning or source repairs.
Freeze this protocol and implementation after development tests and before any
calibration, train, validation or test generation for the registered seeds.
Tests use reserved 980xxx seeds only. Every split and algorithm budget is fixed
in protocol.json. Existing experiments and defaults remain unchanged.

## Generator and information boundaries

Eight continuous standard-normal sensor readings and six noisy continuous cue
values are public. Four latent linear logistic tasks have orthogonal directions
of norm3 generated by a fixed coefficient seed. Supervised calibration provides
8192 public readings and four binary response targets; fit four nine-parameter
logistic experts separately, zero initialization,160 full-batch Adam steps, .05
learning rate, .001 L2 except intercept, fixed bootstrap seeds. Coefficients are
not passed to fitting/inference: only public readings and calibration targets.
Every policy uses these identical36 frozen learned parameters.

Each stream draws four new separated cue templates (norm3, min distance2),
and a new random permutation between contexts and tasks. Cue templates, task
mappings, readings, label uniforms, schedules and cue jitter use independent
PRNG substreams. Thus a cue by itself cannot identify the correct task across
streams. Useful recall requires earlier released feedback from that same stream.
No training/test context IDs, coefficient vectors, task IDs or mappings enter
inference. No context ID is serialized into memory or its embedding.

Blocks last48..96 steps. All four contexts appear once in random order, followed
by new random permutations avoiding adjacent repeats. Repeated-context identity,
age and switches are evaluator-only scoring metadata, attached AFTER all policies
predict. Original cues have .12 per-coordinate noise; noisy-cue case uses .3.
Novel-context case creates a new separated template and random task each block.
Mapping-change case cyclically changes every context's task at the first block
boundary at/after the midpoint, retaining cues and old memory. Random-label case
uses independent balanced labels with identical public cue/readings to recurring.
No-feedback repeats recurring but withholds every label from every policy.
All cases share reading sequences; noisy cues differ only by jitter amplitude.

## Policies and fair controls

Raw expert probabilities become base p=.05+.9*q dot expert_probabilities.
Recency routes q=softmax(-8*fast-error), with .35/.04 fast/slow binary expert
mismatch EWMAs, initialized .5 and updated after released labels.

Episodic memory uses the existing local embedding protocol's encode interface
with an explicit six-dimensional identity cue encoder. This is measured-feature
encoding, not a pretrained semantic embedding. SQLite stores only namespace,
step, public cue/readings, released binary label, four derived expert errors and
embedding version. The RAM search index is reconstructed from SQLite and always
filters step<before_step before taking the latest1024 rows. Nearest cue neighbors
inside a selected radius return mean past expert mismatch. Blend retrieved loss
with global fast loss; evidence weight ramps as min(1,neighbor_count/8).
Choose neighbors[32,64], radius[.75,1.25], blend[.5,1] on validation (8 candidates).
An unseen cue with no eligible neighbor falls back to the same recency policy.

Memory-disabled is exactly recency: same policy with retrieval bypassed. Retain
both names as an equality/control test, not independent scientific baselines.
Shuffled memory has identical history, count, capacity and candidate keys; a fixed
causal PRNG permutes key-to-feedback associations independently at each query,
using only rows already released. No future label or cue is used by the shuffle.

Conventional context cache: at most8 cue centroids, associated four-error EWMA,
and observation count. Query closest centroid within selected radius. After
feedback update centroid by .05, errors by selected rate; new slots start .5,
evict least recently observed when full. Same evidence warmup and recency fallback.
Choose radius[.75,1.25], rate[.1,.35] on validation (4 candidates), blend1.
This is a strong simple conventional memory baseline; no novelty claim follows
from outperforming context-blind recency or a small neural model alone.

Neural recurrent baseline: conventional tanh recurrent router, hidden24, input
current cue/3 plus four fast and four slow error summaries (14 public features),
four-route softmax head,1036 learned parameters. It receives no episodic retrieval
or hidden IDs. Train three fixed initializations for12 epochs on8 fresh1024-step
recurring streams (98304 examples/3072 updates each), Adam .003, truncated BPTT32.
Use continuous expert likelihoods in analytic gradients. Hidden state carries
between chunks, resets between streams. Select model seed and routing temperature
[.5,1,2] on validation (9 candidates). Record every training curve and selection.
Fixed uniform routing is an additional control. All policies get identical
public observations and the same label-release order, and reset between streams.

These are NOT equal-parameter/equal-compute methods. Memory holds up to1024
feedback records for retrieval; its audit transcript retains all2048 observations.
Cache holds8 summaries; recurrent has1036 weights plus24 recurrent state values
and receives extra offline training. Report storage/training budgets and timing,
without computational-efficiency or unlimited-recurrent-model superiority claims.

## Confidence gate and endpoints

For EACH policy also record a companion confidence-shrunk probability using the
unchanged frozen gate and normalization. Inputs retain original meanings:
intercept1, abs(2*base-1), two past base-correctness EWMAs minus .5, two past
base log-gain EWMAs versus uniform, .5-min(fast expert error), .5-min(slow error).
Correctness/log-gain rates .04/.15; history starts at .5/0. No gate training.
Primary metrics and all qualification gates use RAW probabilities so confidence
shrinkage cannot conceal a recall failure. Gated metrics are descriptive only.

Report raw/gated log loss, Brier, accuracy,10-bin confidence ECE, confidently
wrong fraction of ALL predictions at confidence>=.9, high-confidence coverage
and conditional error. Return first16 slices exclude startup and first visits.
Return response delay: first endpoint of an8-label rolling window with raw mean
log loss<=.55, searched up to64 steps and truncated at next switch/end. Ignore
events shorter than8; unrecovered events score64. Report fraction recovered and
counts. This stochastic response metric is not a change detector.

Functional-recall gate: average return-first16 log loss over recurring/noisy-cue
cases WITHIN each of24 independent test seeds; memory must beat disabled,
shuffled, recency AND recurrent by>=.02 nats with each paired95% upper bound<0.
Speed gate: mean penalized return response at least2 steps faster than recency
AND recurrent, each paired95% upper bound<0. Duplicated disabled/recency are the
same evidence. Primary success is the conjunction of all requirements, not a
choice of whichever comparator looks favorable.

Quality gate: on novel, stale-mapping and random-label cases raw memory loss
<=recency+.02 (.03 for stale mapping), Brier<=recency+.01, confidently-wrong
<=recency+.01. Every policy random-label accuracy must be within .02 of .5.
The raw route mixture cannot generally become uniform for every observation,
so its random-label quality is compared with recency using the same experts.
Separately report whether the frozen gate companion achieves random-label loss
<=log(2)+.03; this descriptive check cannot rescue any failed raw gate.
Qualification requires functional recall, speed AND
quality. A descriptive extra value gate requires overall raw primary-case loss
<=context-cache-.01 with paired upper95%<0 before preferring episodic retrieval
over the simpler cache. Keep this separate from functional recall.

Bootstrap10000 draws resamples whole24 seed blocks, after averaging paired cases
within seed. Steps/cases are not independent replicates. Conjunction tests require
every comparator; individual intervals are not simultaneous confidence bands.
Intervals condition on a single supervised expert fit and validation selection;
they exclude fit/selection uncertainty. Record selection+hash before generating
any test stream; no novel/stale/random test family enters selection.

## Verification and preservation

Save every candidate score and trained recurrent checkpoint; selected checkpoint,
unchanged gate, source snapshots/hashes, every stream and raw/gated prediction.
144 streams *7 policies *2048 steps =2064384 raw predictions plus the same number
of gated companion probabilities. Separate-process proof must refit experts,
retrain all three recurrent candidates, repeat selection, regenerate/replay every
prediction, recompute all scores/slices/delays/bootstrap/gates and reconstruct
memory, shuffled-control RNG, cache and recurrent state before step1024 from
strictly earlier SQLite feedback. Future rows in that DB must be excluded.
Persist only one complete representative stream for resume proof; other streams
use the identical memory engine with in-memory SQLite. Never query another
stream's namespace. No-feedback must leave memory empty.

Verify prior artifacts/project files, clean pinned NVIDIA checkout, absent listed
provider keys and active Python socket guard. No downloads, APIs, pretrained
peptide weights, services, GPU/QPU jobs or live-assistant changes. The process
guard is not an OS sandbox. No public or real-world capability claim follows.

## Export-recovery v2, frozen before fresh registered data

The earlier run results/recurring-memory-v1 is incomplete: numpy.bool_ in the
descriptive gated random-loss check prevented JSON summary export after all
streams completed. Its source, settings, traces and failure log are preserved.
This separate package converts only that comparison to native Python bool.
All scientific algorithms, candidate grids, capacities, endpoints and thresholds
remain unchanged. No v1 held-out metrics were used for changes or selection.
All stochastic seeds, including calibration, world coefficients, expert fitting,
training, validation, test, shuffling and bootstrap, are fresh and disjoint.
All original freeze and no-repair rules apply to this new registered experiment.
An added development-only integration test exercises export/report/reload and
verification on reserved 980xxx seeds before any registered v2 data generation.
