# Documentation precision

The frozen DEVELOPMENT.md sentence about development seeds refers to generated
world streams. Before the fixture correction, the abstract bootstrap unit test
also used the inherited bootstrap seed on a fixed six-number toy vector. No
registered calibration, training, validation or held-out world stream was
generated by that test. The final fixture uses its own bootstrap seed as well.
The frozen record and all failed-log digests are retained.

Every validation candidate is saved in selection.json. The generated RESULTS.md
closing sentence groups this with results.json; results.json itself contains
the metrics, world/stream records, comparisons and gates, plus the selection
file digest. The source, numeric results and gates are unchanged by this note.

retrieved_count counts all radius-matched candidates within the 256-record
search view. stable_count and fast_count describe the capped branch subsets.
The stores are disjoint FIFO views, not compressed long-term concept banks;
the stable view can still lose a concept when its records leave the 256-row
active search span. No equal total-memory or equal-compute claim is made.
